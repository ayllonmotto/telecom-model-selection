# Datos

El dataset original **no se distribuye en este repositorio**.

Para ejecutar el proyecto, coloca una copia obtenida por una vía autorizada en esta carpeta con el nombre:

```text
BBDD_ML_TAREA.csv
```

La ruta esperada por los scripts es:

```text
data/BBDD_ML_TAREA.csv
```

Durante la ejecución se generarán objetos intermedios en `outputs/`. Estos archivos están excluidos del control de versiones mediante `.gitignore`.
