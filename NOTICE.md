# Avisos y materiales de terceros

## Autoría

El código, el texto y la documentación originales incluidos en esta versión de portfolio son obra de **Carlos Ayllón Motto**.

Estos contenidos originales se distribuyen bajo licencia MIT. Consulta `LICENSE`.

## Origen académico

El proyecto parte de una actividad académica de Machine Learning centrada en un problema de clasificación binaria aplicado al riesgo de abandono de clientes de telecomunicaciones.

La versión de este repositorio ha sido revisada y preparada posteriormente para su presentación como pieza de portfolio profesional.

## Dataset

El archivo original `BBDD_ML_TAREA.csv` fue proporcionado en el contexto académico.

**El dataset original no se incluye ni se redistribuye en este repositorio.**

Para reproducir el proyecto es necesario obtener los datos a través de una fuente autorizada y respetar sus condiciones de uso.

## Materiales docentes y entregables académicos

No se incluyen ni redistribuyen:

- el enunciado original de la actividad;
- documentos o materiales docentes;
- el dossier académico de entrega;
- objetos serializados `.pickle`, `.pkl` o equivalentes;
- el conjunto completo de figuras generado durante el desarrollo.

## Figuras incluidas

Las imágenes publicadas en `images/` son una selección de salidas gráficas **regeneradas con los scripts finales** y se incorporan para documentar el proceso analítico, los ajustes de modelos y los resultados del portfolio.

La licencia MIT de este repositorio no debe interpretarse como una concesión de derechos sobre el dataset subyacente ni sobre materiales académicos o de terceros.

## Librerías y software de terceros

El proyecto utiliza librerías de terceros, entre ellas NumPy, pandas, Matplotlib, Seaborn, SciPy, scikit-learn y XGBoost. Cada una mantiene sus propias licencias y condiciones de uso.

## Alcance

Este repositorio tiene como finalidad mostrar el enfoque analítico, la metodología de modelado, la comparación de algoritmos y la capacidad de estructurar un flujo reproducible de Machine Learning como parte de un portfolio profesional.
